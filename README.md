# CI2 - Chicken Invaders 2 Reversed

Reverse engineering work on Chicken Invaders 2, the original 2002 
release by InterAction Studios.

The game was built with Borland C++ and uses the UveDX7 engine 
(Ultra VGA Engine DirectX 7).

## What's Here

Function names, class structures, and source file paths extracted 
from the original ChickenInvaders2.exe.

## How

The devs left debugging strings in the binary. These strings contain 
source file paths and function names. Extracted them and mapped them 
back to the code.

## Engine

UveDX7 - Ultra VGA Engine DirectX 7
By Konstantinos Prouskas / InterAction Studios
Year 2003
